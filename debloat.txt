# OnePlus TV Y1S (model D00, codename Dubai), Android TV 11, firmware RTM1.210315.027, 920 MB RAM
# Live TV app: com.heytap.tv.livetv. Stock launcher: com.google.android.tvlauncher.
#
# Everything here is DISABLED for user 0 (pm disable-user --user 0), never uninstalled.
# Undo all of it:  tools\restore.ps1      (or: tools/venv/Scripts/python.exe -I tools/restore.py)
# Re-enable one:   tools\tv.ps1 "pm enable --user 0 <package>"
# Comment a line out (#) to keep that package next time the list is applied.
#
# Already disabled before we started (left as they were, restore does not touch them):
#   com.heytap.olink, com.oneplus.tv.remote
#
# Kept on purpose, the TV needs them: com.heytap.tv.livetv (Live TV + source list),
# com.mediatek.tvinput (HDMI/AV/tuner), com.mediatek.tv.service (hot keys, Netflix key),
# com.google.android.tv.remote.service (remote), com.android.bluetooth, Gboard, Play Store,
# Play Services, TV Settings, com.google.android.tungsten.setupwraith (on this firmware it hosts
# system updates, saved Wi-Fi and remote pairing, and does not claim HOME), factory menus.
# Kept because unclear: com.heytap.tvapiservice (log upload, but also auto-standby / kids mode /
# far-field mic, and it runs com.heytap.optvbtlink.services.BTDetectService, a Bluetooth link service
# that likely serves the remote: do not disable), com.heytap.tv.remotecontrolinspect.
# Kept by choice: Chromecast (com.google.android.apps.mediashell), File Manager
# (com.heytap.tv.filebrowser), Bluetooth Stereo (com.heytap.tv.btspeaker), Netflix, Prime Video,
# YouTube, YouTube Music, JioHotstar, ZEE5, Crunchyroll.
